# ERA5 Downloader
A Python tool for downloading ERA5 climate reanalysis data from the Copernicus Climate Data Store (CDS)
## Installation
1. Clone the repository:

  ```bash
  git clone https://github.com/ShadowNinjaCat/era5-downloader.git
  ```

2. Create a virtual environment:
```bash
python -m venv .venv
source .venv/bin/activate  # Windows:.venv\Scripts\activate
pip install -r requirements.txt
```

3. setup enviorement variables:

```bash
cat .env.example > .env
```
Edit the .env file and add your CDS credentials. This can be found on [cds credentials](https://cds.climate.copernicus.eu/how-to-api).

4. Configure CDS credentials:

```bash
python core/setup/setup_era5.py
```
This will create the $HOME/.cdsapirc file with your credentials.

## Configuration
Modify the config/era5_request.yaml file according to your data requirements. Here's an example configuration:
```yaml
save_folder: data/
dataset: reanalysis-era5-single-levels
request:
  product_type: reanalysis
  format: grib
  variable: [sea_surface_temperature]
  year: ['2020', '2021']
  month: ['06', '07', '08', '09', '10']
  day: ['01', '02', '03', '04']
  hour: ['00:00', '06:00', '12:00', '18:00']
  area: [40, -180, 0, -80] # [North, West, South, East]
```
### config options:
* **dataset**: Choose from ERA5 datasets like reanalysis-era5-single-levels or reanalysis-era5-pressure-levels

* **variable**: List of meteorological variables to download

* **time range**: Specify years, months, days, and hours

* **area**: Define geographical boundaries as [North, West, South, East]

* **format**: Output format (grib or netcdf)

## Use
1. Submit Data Requests:
```bash
python core/era5_request.py --config config/era5_request.yaml
```
This file submits requests to the CDS API and creates a requests.json file with request information.

2. Download the data:
```bash
python core/era5_download.py --request-json custom_requests.json --poll-interval 30
```
This comand monitors, downloads, and handles failed requests automatically using polling to check request status.

**Notes**: By default it uses request.json file (generated by era5_request.py) and poll-interval == 60.
